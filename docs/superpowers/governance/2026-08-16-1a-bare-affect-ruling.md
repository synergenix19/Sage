# Conformance-owner ruling — §1a bare-affect offers (2026-08-16)

**RULED (PO, conformance owner, in-session 2026-08-16): bare-affect direct-offer remains
conformant this phase; the oracle's §1a rows stand as written. Screen-first-on-bare-affect
is a KNOWN DEVIATION with a named closure path, not a defect.**

**Reasoning (owner's, recorded verbatim in substance):** BOT BEHAVIOUR §1a's step-2 screen
precedes the offer in the spec's authored flow — but that flow was written for the guided
pathway, and the EMR campaign's clinical rulings (Vee's signed screen-gating) deliberately
scoped screen-first to the explicit-request path, where a user is asking to RECEIVE a tool
and the §1a-§6 guards must clear first. Bare-affect matching ("I feel a bit anxious" →
consent-gated offer) serves an OFFER, not a delivery — the consent gate is itself a
screen-adjacent checkpoint, and the user accepts or declines. Retrofitting screen-first
onto every bare-affect turn now would (a) change served behavior ahead of any clinical
ruling requesting it, (b) invalidate the fresh baseline before it is run, and (c) apply
Vee's request-path signature beyond its scope — the exact extrapolation this stream
refuses.

## The two readings, drafted for the closure path

**Reading A — current phase (RULED, this document):** §1a bare-affect turns offer directly
through normal matching + the R1 consent gate; screening gates the explicit-request path
only (Vee's signed scope). Oracle expectation for §1a rows: `skill`
(box_breathing / grounding first-line family), as written.

**Reading B — the candidate future (Vee's line to rule):** the §1a step-2 screen precedes
EVERY first offer in an anxiety context, including bare-affect matches: the first
skill-offerable turn serves the signed screen question instead, the answer clears (or
routes per red-flag/chronic rules), and the offer follows. Oracle expectation would become
screen-first for §1a bare-affect rows; the change is a governed behavior change with its
own oracle re-spec, fixture family, and measurement against the new baseline.

**Closure path:** Reading B goes on the next Vee sheet as its own line — "should
bare-affect offers also screen first?" Her ruling decides the future; this ruling decides
this phase. Any future flip = governed change, measured against the baseline this ruling
unblocks.
